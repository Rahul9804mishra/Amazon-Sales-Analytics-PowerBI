# Amazon Sales Analytics Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Amazon sales
performance and understand sales trends, order performance, product categories,
fulfillment, and geographical distribution.

The dashboard provides a consolidated view of important business metrics and
allows users to explore the data using interactive filters.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall Amazon sales performance
- Track important sales KPIs
- Understand sales performance across product categories
- Analyze order status and fulfillment performance
- Identify sales trends over time
- Compare sales performance across different states
- Provide an interactive dashboard for business analysis

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

---

## 📌 Key KPIs

The dashboard includes the following key performance indicators:

- Total Sales
- Total Orders
- Units Sold
- Fulfillment Rate
- Average Order Value

These KPIs provide a quick overview of the overall sales and order performance.

---

## 📈 Dashboard Features

### 1. Sales Overview

The dashboard displays total sales, total orders, units sold, fulfillment rate,
and average order value as high-level KPIs.

### 2. Category Analysis

Sales are analyzed across different product categories to understand which
categories contribute most to overall sales.

### 3. Order Status Analysis

The dashboard provides an overview of orders based on their current status,
including shipped, cancelled, pending, and other available order statuses.

### 4. Time-Based Analysis

Sales performance is visualized across months to identify changes and trends
in sales over time.

### 5. Geographical Analysis

Sales are analyzed across Indian states to understand the geographical
distribution of sales.

### 6. Interactive Filters

The dashboard includes interactive filters that allow users to analyze the
data based on:

- Date
- State
- Category
- Order Status

These filters allow users to explore specific parts of the dataset.

## 💡 Key Insights

Based on the dashboard:

- The dashboard records approximately ₹78.59M in total sales.
- Approximately 120.378K orders are represented.
- Approximately 117K units have been sold.
- The fulfillment rate shown on the dashboard is approximately 60.32%.
- Set is the largest contributing product category in the displayed category
  analysis.
- Maharashtra has the highest sales among the states shown in the dashboard.
- Sales vary across the months represented in the dataset.
